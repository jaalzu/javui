# @javui/ui

React-first accessible UI components for Next.js and other React applications.

Install `@javui/ui` with React, React DOM and `@base-ui/react`. Import `@javui/ui/tokens.css` and optionally `@javui/ui/base.css`, `@javui/ui/fonts.css`, or the compatibility entry `@javui/ui/global.css`. Server-side code highlighting is available separately from `@javui/ui/server` and requires the optional `shiki` peer.
